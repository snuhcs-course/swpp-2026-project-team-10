# Person-check test set: sources

All photos are from Wikimedia Commons. Each was downloaded as the thumbnail that the API returned for `iiurlwidth=1600` (Commons serves its nearest standard size, mostly 1920 px wide, or the original when that is smaller; the served size is listed). Each was then rotated by its EXIF orientation, converted to RGB, cropped to the portrait box listed below (given in the original file's pixels), resized with Lanczos, and saved as JPEG quality 90 with no EXIF or other metadata. Nothing else was changed.
